Team 6 · Concept Induction on Michalski’s Trains

We wrote a Python script with rdflib that converts each dataset into an OWL ontology. Every train, wagon and load is an individual. Categorical values become classes, arranged in the open-top versus closed-top hierarchy that comes with the UCI data, and sibling classes are declared disjoint. Relations become object properties: hasCar, hasLoad and inFrontOf for wagon order. Numbers like wheels and position are data properties. Two important choices: the label is never asserted, so nothing leaks; and we built a second version with closure axioms, which says a train has only these wagons, so we could test learning under the open-world assumption.
